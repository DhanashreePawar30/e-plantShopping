# Paradise Nursery — e-plantShopping

A responsive React and Redux Toolkit houseplant shopping application.

## Features
- Landing page with background image, company introduction, and Get Started button
- 18 plants in three categories
- Add-to-cart buttons disable after adding a plant
- Shared navigation with a live cart count
- Redux Toolkit cart state
- Increase, decrease, and delete cart items
- Per-item subtotals and grand total
- Checkout placeholder and continue-shopping navigation
- Responsive layout

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

## GitHub Pages deployment
Create a public repository named `e-plantShopping`, push the files, then run `npm install` and `npm run deploy`. In GitHub, enable Pages for the `gh-pages` branch. The URL is usually `https://YOUR-USERNAME.github.io/e-plantShopping/`.

Checkout is a demonstration only and does not process payments.
